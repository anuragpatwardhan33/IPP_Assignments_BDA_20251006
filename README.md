# Image Processing using Python :  Assignment 2 and Assignment 3

This repository contains Jupyter Notebook work and supporting input images for Image Processing (IPP) Assignments 2 and 3, using Python, OpenCV, Pillow, NumPy, Matplotlib, and related image-processing libraries.

## Assignment 2 : 

**Notebook:** `IPP_Assignment_2_BDA_20251006.ipynb`

Assignment 2 :

1. **Read and Display an Image Using OpenCV** — reads `flower.jpg`, prints dimensions and data type, and displays the image.
2. **Display Image Dimensions and Data Type** — reads `scene.jpg` and prints height, width, channel count, and data type.
3. **Convert a Color Image to Grayscale** — converts `scene.jpg` to grayscale and saves `output_gray.jpg`.
4. **Display an Image Using Pillow** — opens and displays `sunset.png`.
5. **Resize an Image to 50%** — resizes `scene.jpg` to half its original width and height.
6. **Crop the Center 200 × 200 Pixels** — crops and displays a central region of `scene.jpg`.
7. **Rotate an Image 90° Clockwise** — rotates `scene.jpg` clockwise.
8. **Flip an Image Horizontally** — flips `car.jpg` from left to right.
9. **Convert an Image to HSV** — converts `scene.jpg` to HSV and displays the Hue, Saturation, and Value channels.
10. **Calculate Mean Squared Error (MSE)** — converts `img1.jpg` and `img2.jpg` to grayscale and calculates MSE. The two images must have the same dimensions.

### Assignment 2 input images

- `flower.jpg`
- `scene.jpg`
- `sunset.png`
- `car.jpg`
- `img1.jpg`
- `img2.jpg`

`output_gray.jpg` is generated by Program 3 when it runs.

## Assignment 3 :

**Notebook:** `IPP_Assignment_3_BDA_20251006.ipynb`

Assignment 3 :

1. **Comparative Edge Detection on Natural Images** — applies Sobel, Laplacian, and Canny edge detection and compares the results.
2. **Noise Sensitivity Experiment** — adds Gaussian and salt-and-pepper noise, compares Sobel and Laplacian responses, and tests noise-reduction filters.
3. **Compression Ratio Comparison (RLE vs Huffman)** — compares estimated bit lengths and percentage reduction for Run-Length Encoding and Huffman coding.
4. **JPEG Block Artifact Analysis** — demonstrates 8 × 8 DCT-based quantisation and compares reconstructed images using MSE, PSNR, and SSIM.
5. **Texture-Based Segmentation using GLCM Features** — extracts GLCM contrast, energy, and homogeneity and uses K-means clustering with three clusters.
6. **Multi-Feature Segmentation for Disease Detection** — combines intensity, Sobel gradient magnitude, and local texture variance for K-means segmentation.

### Assignment 3 input images

- `natural.jpg` — used in Problems 1 and 2.
- `smooth.png` — used in Problem 3.
- `city.jpg` — used in Problem 4.
- `textures.jpg` — used in Problem 5.
- `plant_disease.jpg` — used in Problem 6.

These are sample images for demonstrating and testing the methods. 

## Requirements

The notebooks use these Python packages:

- OpenCV (`opencv-python`)
- NumPy
- Matplotlib
- Pillow
- scikit-learn
- scikit-image

Install the packages in a Python environment with:

```bash
python -m pip install opencv-python numpy matplotlib pillow scikit-learn scikit-image
```

## How to Run

1. Download this repository.
2. Keep each notebook's required input images in the same working folder, or update the image paths in the notebook.
3. Open the relevant `.ipynb` file in Jupyter Notebook or JupyterLab.
4. Run the cells from top to bottom.
5. Check that each program displays its output before saving the notebook.
